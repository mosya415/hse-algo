# Задача 3. Balanced Binary Tree

Решение в `balanced_binary_tree.py`, тесты в `test_balanced_binary_tree.py`.

    python3 balanced_binary_tree.py
    python3 test_balanced_binary_tree.py

## Идея

Обхожу дерево снизу вверх: сначала дети, затем родитель. Высота пустого поддерева равна 0, высота листа равна 1. Для остальных узлов высота равна `1 + max(высота слева, высота справа)`.

Высоты уже обработанных узлов сохраняю в словаре. Для каждого родителя сравниваю высоты детей. Если разница больше 1, сразу возвращаю False. Если такого узла нет, возвращаю True. Так проверяется баланс у каждого узла, и высоту одного поддерева не приходится считать заново.

Функция `is_balanced` принимает корень дерева из узлов `Node`. Значения узлов могут идти в любом порядке, здесь проверяется только высота поддеревьев.

## Сложность

Время O(n): высота каждого узла вычисляется один раз. Память O(n) на словарь высот и стек обхода.

## Пример

            10
           /  \
          5    15
         /    /  \
        3    12   18
       /
      1

| Шаг | Узел | Высота слева | Высота справа | Результат |
|-----|------|--------------|---------------|-----------|
| 1 | 1 | 0 | 0 | высота = 1 |
| 2 | 3 | 1 | 0 | высота = 2 |
| 3 | 5 | 2 | 0 | разница 2, возвращаем False |

У корня высоты поддеревьев равны 3 и 2, разница всего 1. Но дерево всё равно несбалансировано из-за узла 5. Поэтому одной проверки корня недостаточно.

## Тесты

Пустое дерево, один и два узла, равные высоты и разница ровно 1. Есть цепочки в обе стороны, нарушение баланса ниже корня и длинное дерево. Значения узлов на баланс не влияют, это тоже проверяется.
