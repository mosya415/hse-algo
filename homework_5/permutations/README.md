# Задача 2. Permutations

Решение в `permutations.py`, тесты в `test_permutations.py`.

Команды запускаются из `homework_5`:

    echo "2 4 7" | python3 -m permutations.permutations
    python3 -m unittest permutations.test_permutations

## Идея

На каждом шаге выбираю первый элемент перестановки. Затем рекурсивно получаю перестановки оставшихся элементов и приписываю выбранное значение в начало каждой из них. Перебирая все варианты первого элемента, получаю все перестановки массива.

Пустой остаток возвращает `[[]]`: это одна пустая перестановка, к которой можно приписать выбранный элемент. Например, выбрав 7 из `[7]`, получаю пустой хвост и превращаю его в `[7]`.

Если значения повторяются, одинаковое начало выбирается один раз. Для этого в каждом вызове есть набор `chosen`. Так в ответе не будет одинаковых перестановок. Элементы перебираются в исходном порядке.

Вложенная функция `generate` обёрнута декоратором из первой задачи. Трассировка включена по умолчанию. Вызов `permutations(nums, trace=False)` возвращает ответ без вывода.

## Сложность

Для n разных элементов существует n! перестановок, в каждой n элементов. Построение ответа занимает O(n * n!) времени. Память O(n * n!) занимают списки перестановок, глубина рекурсии равна O(n).

При включённой трассировке добавляется O(S) времени на вывод, где S это число напечатанных символов. Он включает аргументы, результаты и отступы каждого вызова. Для повторяющихся значений перестановок будет меньше, оценка выше остаётся верхней границей.

## Пример: [2, 4, 7]

Первым выбирается 2. Остаётся получить перестановки `[4, 7]`, затем поставить перед ними двойку. Начало вывода:

    -> generate([2, 4, 7])
      -> generate([4, 7])
        -> generate([7])
          -> generate([])
          <- generate = [[]]
        <- generate = [[7]]
        -> generate([4])
          -> generate([])
          <- generate = [[]]
        <- generate = [[4]]
      <- generate = [[4, 7], [7, 4]]

Вернулись хвосты `[4, 7]` и `[7, 4]`. Добавляем 2 и получаем `[2, 4, 7]` и `[2, 7, 4]`. Остальные ветки работают так же:

| Выбран первый элемент | Остаток | Перестановки остатка | Добавлено в ответ |
|----------------------|---------|---------------------|-------------------|
| 2 | [4, 7] | [4, 7], [7, 4] | [2, 4, 7], [2, 7, 4] |
| 4 | [2, 7] | [2, 7], [7, 2] | [4, 2, 7], [4, 7, 2] |
| 7 | [2, 4] | [2, 4], [4, 2] | [7, 2, 4], [7, 4, 2] |

Ответ:

    [[2, 4, 7], [2, 7, 4], [4, 2, 7], [4, 7, 2], [7, 2, 4], [7, 4, 2]]

## Тесты

Все примеры из условия, пустой массив, отрицательные числа и ноль, неотсортированный вход, повторяющиеся и одинаковые значения. Для четырёх разных элементов проверяются 24 разных перестановки. Отдельно проверяется точный вывод стека с результатами и отключение трассировки.
