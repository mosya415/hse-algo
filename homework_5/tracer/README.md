# Задача 1. Tracer

Решение в `tracer.py`, тесты в `test_tracer.py`.

Команды запускаются из `homework_5`:

    echo 4 | python3 -m tracer.tracer
    python3 -m unittest tracer.test_tracer

## Идея

Декоратор `@tracer` оборачивает функцию. Перед вызовом он печатает её имя и аргументы, затем увеличивает глубину на 1. После завершения глубина уменьшается, и печатается возвращённое значение. Каждый уровень добавляет два пробела к отступу.

Глубина общая для всех функций с этим декоратором. Поэтому вложенный вызов другой декорированной функции тоже получает нужный отступ. Уменьшение глубины находится в `finally`: если функция завершилась с ошибкой, счётчик всё равно восстановится, а ошибка передастся дальше.

Позиционные и именованные аргументы передаются исходной функции без изменений. `wraps` из стандартной библиотеки сохраняет её имя и описание. Результат возвращается вызывающему коду, а не только печатается.

## Сложность

Декоратор печатает две строки на обычный вызов. Его время O(S), где S это общее число выведенных символов. Память O(h + L), где h это глубина рекурсии, а L максимальная длина строки вывода: в памяти находятся обёртки вызовов и строка, которая сейчас печатается. Работа самой функции в эту оценку не входит.

## Пример: factorial(4)

В файле есть рекурсивный факториал с `@tracer`. При вызове `factorial(4)` получается:

    -> factorial(4)
      -> factorial(3)
        -> factorial(2)
          -> factorial(1)
          <- factorial = 1
        <- factorial = 2
      <- factorial = 6
    <- factorial = 24

Входы идут до `factorial(1)`, где возвращается 1. Затем вызовы завершаются в обратном порядке: `2 * 1 = 2`, `3 * 2 = 6`, `4 * 6 = 24`. Отступ при возврате совпадает с отступом входа в тот же вызов.

## Тесты

Проверяются входы и результаты факториала, отступы при двух ветках рекурсии, именованные аргументы и функция без аргументов с результатом None. Ещё есть вложенные декорированные функции, восстановление глубины между вызовами и после ошибки, сохранение имени и описания функции.
